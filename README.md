# ToDo Web App

React・Express・MongoDBを用いたフルスタックのToDo Webアプリケーションです。ユーザ認証後、自分のタスクを追加・編集・削除し、締切やメモ、完了状態を管理できます。

## 主な機能

- 新規登録 / ログイン / ログアウト
- JWTを用いた認証
- タスクの追加・編集・削除
- 完了 / 未完了の切り替え
- 締切日の設定と期限超過表示
- メモの登録
- 完了済みタスクの表示切り替え / 一括削除
- ユーザごとのタスク分離

## 使用技術

- React
- Node.js / Express
- MongoDB
- JWT (jsonwebtoken)
- bcryptjs
- Parcel

## 公開版での整理

公開にあたり、個人情報・授業用の途中ファイル・開発ツール固有の設定ファイルを除外し、公開環境向けに構成を整理しています。また、認証情報を安全に扱うため、パスワードのハッシュ化とユーザごとのタスク分離を追加しています。

## ローカル実行

1. 依存パッケージをインストールします。

```bash
npm install
```

2. `.env.example` を参考に `.env` を作成します。

```text
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017
DB_NAME=todo_portfolio
JWT_SECRET=十分に長いランダム文字列
NODE_ENV=development
```

3. フロントエンドをビルドしてサーバを起動します。

```bash
npm run build
npm start
```

4. ブラウザで `http://localhost:3000/` を開きます。

## 公開時の注意

- `.env` はGitHubにアップロードしません。
- `JWT_SECRET` は公開環境で推測されにくい長い値を設定します。
- MongoDBの接続文字列はホスティングサービス側の環境変数として設定します。
- 公開デモでは、普段使用しているパスワードを入力しないでください。

## 元の制作物からの変更点

公開版は、制作時の機能をもとに公開しやすい形へ整理したものです。パスワードのハッシュ化、ユーザ間のタスク分離、入力チェック、公開用の画面・ファイル構成の整理は公開準備時に追加しています。
